MELMAN & CO. — GitHub / Cloudflare Pages

1. Uploadajte SAV sadržaj ovog ZIP-a u root GitHub repozitorija.
2. U Cloudflare Pages odaberite taj repo.
3. Framework preset: None. Build command: ostavite prazno. Output directory: / (root).
4. Privremeni SEO URL u sitemap.xml, canonical i structured data je: https://melman-co.pages.dev
   Ako Cloudflare projekt nazovete "melman-co", taj pages.dev URL će odgovarati.
5. Kada spojite vlastitu domenu, pretražite projekt za "https://melman-co.pages.dev" i zamijenite ga konačnom https domenom, zatim ponovo deploy.

Kontakt forma: Web3Forms AJAX, access key je već ugrađen prema briefu.
