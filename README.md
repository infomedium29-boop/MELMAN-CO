# MELMAN & CO — Cloudflare Pages verzija

Ova verzija koristi direktorijske URL-ove (`/projekti/`, `/kontakt/` itd.) kako bi sve podstranice pouzdano radile na Cloudflare Pages bez `.html` redirect petlji.

## Deploy
- Build command: nije potreban
- Build output directory: korijen repozitorija
- Sve datoteke iz ovog ZIP-a stavite direktno u root GitHub repozitorija.
